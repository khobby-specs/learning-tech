## Why This Exists

Three academic years were disrupted by circumstances outside my control. Rather than wait for a system that was not moving, I built my own structure. This repo is that structure made public.

The target is AI Security Engineering — specifically the intersection of adversarial machine learning, offensive security, and systems architecture. The long-term goal beyond the career is two startups: a MoMo fraud detection platform for West African telcos, and a cold chain logistics platform addressing the $48–60B annual post-harvest loss problem across sub-Saharan Africa.

Everything in this repo is building toward both.
