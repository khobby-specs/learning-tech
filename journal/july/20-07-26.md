### New Commands Learned
1. **Force Stage Files**
   * `git add -f <filename>`
   * *What it does:* Forces Git to track and stage a file, even if a rule or a confusing subdirectory structure is trying to ignore it.

2. **Repository File Search**
   * `find . -name "*.md"`
   * *What it does:* Searches the current directory and all subfolders to locate files matching a specific pattern (like markdown files).
