📋 Operator Instructions

Editing Scores: Click any score cell to edit. Type the new score and press Enter or click away to confirm.

Ranking: Districts automatically rank by total score. Gold (1st), Silver (2nd), Bronze (3rd) highlights appear instantly.

Round Navigation: Use Previous/Next buttons to move between rounds. The active round is highlighted.

Round 4 Shows: A "Total" column displaying the grand total of all 4 rounds.

Export: Downloads a new HTML file with all scores baked in. Perfect for archiving or sharing.

Reset: Clears all scores. Confirmation required.

VMix Setup: Load this file as HTML overlay at 1920×1080 resolution. Go to VMix Input > Add Input > Web Browser > Point to this file.

Logo: Find the SVG placeholder at the top of the source code. Replace with your actual Apostolic Church Ghana logo (PNG or SVG).
